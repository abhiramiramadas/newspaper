Open Source Projects Establish Bans on AI-Generated Code

A growing list of open-source repositories opt out of accepting automated code contributions.

A community initiative, osssaysno.com, tracks open-source software projects that have formally banned AI-generated code contributions. Project maintainers cite concerns over code quality, subtle logic bugs, license ambiguity, and the overwhelming volume of low-effort pull requests generated by automated assistants. The movement reflects an ongoing debate within developer communities regarding the boundary between helpful developer tools and maintainer fatigue, as teams seek to protect open-source software standards against unsupervised AI contributions.

Maintainers are drawing boundaries around code review quality, copyright clarity, and repository health.
