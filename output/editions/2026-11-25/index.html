Taxi System Scales Debugging and Querying for Millions of Agent Trajectory Steps

A new infrastructure framework combines automated clustering, SQL access, and decision models to monitor agent behavior at scale.

Researchers have introduced Taxi, a scalable debugging, clustering, and monitoring system designed to handle millions of agent execution steps. Taxi creates structured taxonomies of agent steps via automated clustering and provides full SQL access for developers and automated agents to query execution logs. The system also integrates Jev-style decision models to enable low-cost semantic routing and probabilistic evaluations where standard embeddings or literal queries fall short.

Provides crucial developer tooling for inspecting, querying, and diagnosing complex autonomous agent behaviors.

ChartInt Benchmarks Interactive Chart-to-Code Generation for MLLMs

A new benchmark evaluates dynamic chart states, tooltips, and cross-chart styling across multi-step user interactions.

Researchers have introduced ChartInt, the first benchmark dedicated to evaluating multimodal large language models on generating interactive charts. Containing 2,779 annotated examples, ChartInt tests MLLMs on dynamic user behaviors including hover states, highlights, tooltips, and real-time data updates. The benchmark uses a state snapshot protocol to measure behavioral consistency across sequential interactions, filling a major gap in evaluating code generation for interactive data visualizations.

Establishes standard metrics for evaluating AI model competence in generating rich, stateful user interfaces.
