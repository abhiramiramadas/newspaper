Benchmark Study Isolates Context and Skill Management in Self-Evolving Autoresearch Agents

Researchers analyze how context folding and lesson retention drive performance in long-horizon scientific agents.

A systematic study examining long-horizon, self-evolving autoresearch agents reveals how harness design choices dictate performance in scientific discovery tasks. Evaluating models like gpt-oss-120b and gpt-6 across benchmarks such as MLE-Bench and KernelBench, researchers discovered that context folding—preserving individual attempt records rather than rolling summaries—improves task performance by up to 19.2%. Additionally, selectively discarding unused skills prevents cognitive clutter, proving that harness structure is as vital as model scale.

Understanding harness design choices provides a practical roadmap for building more capable, self-improving AI research systems.

AutoPILOT Harness Enables AI Agents to Perform Real-Time Control in Fast-Paced Video Games

By allowing closed-loop micro-controllers between model calls, AutoPILOT drastically improves agent responsiveness in real-time environments.

Computer science researchers have introduced AutoPILOT, a visual agent harness designed to overcome latency limitations in real-time video games. Unlike conventional harnesses that trigger only one action per model inference, AutoPILOT allows agents to launch open-loop macros or execute closed-loop controllers directly from screen input between full model calls. Tested on AFK-Bench, AutoPILOT achieved a 68.6% real-time success rate compared to 38.3% for standard harnesses, significantly advancing real-time agent execution.

Closing the latency gap in real-time decision-making is critical for deploying visual AI agents in dynamic physical and virtual domains.
